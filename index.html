歼‑20 两相吸波填料电磁参数虚拟仿真

一、基础材料本征参数

碳纳米管：ε'=15.0，ε''=3.0，μ'=1.0，μ''=0.002

羰基铁粉：ε'=18.0，ε''=4.5，μ'=2.8，μ''=1.12

二、计算公式（Lichtenecker对数混合模型）

lnε'ₑff = v₁·lnε'₁ + v₂·lnε'₂

lnε''ₑff = v₁·lnε''₁ + v₂·lnε''₂

lnμ'ₑff = v₁·lnμ'₁ + v₂·lnμ'₂

lnμ''ₑff = v₁·lnμ''₁ + v₂·lnμ''₂

介电损耗正切：tanδₑ,ₑff = ε''ₑff / ε'ₑff

磁损耗正切：tanδₘ,ₑff = μ''ₑff / μ'ₑff

简化相对本征阻抗：ηₑff = √( μ'ₑff / ε'ₑff )

符号说明：v₁：碳纳米管体积分数；v₂=1−v₁：羰基铁粉体积分数

三、组分比例调节

碳纳米管体积分数：50 %

羰基铁粉体积分数：50 %

四、仿真计算结果

tanδₑ,ₑff tanδₘ,ₑff ηₑff
